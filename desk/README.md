# The desk

Will Fullerton's own view into Krafft and Watermark, at fullerton.cloud. Separate from the house; secret; one page set like a magazine's front. Every source is optional and says quietly when it is not connected.

Run: `npm install && DESK_EMAIL=you@example.com npm start` → http://localhost:4100 (with no RESEND_API_KEY the sign-in code is printed in the log). Test: `npm test`.

Deploy by hand on Render (a blueprint sync would create a paid service): see `render.example.yaml` for the environment. The Watermark service needs the same `DESK_KEY` set; it answers `/api/desk` only to that key.

The figure (`public/figure.svg`) is an original character, a first draft: a gentleman in profile, a homburg, round spectacles, a photograph held up to the light, the keys on their tassel. He wants a name and a better hand; Will's call.
